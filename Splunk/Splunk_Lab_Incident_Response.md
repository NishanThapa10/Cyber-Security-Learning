**Course Unit:** Identity Access Management and Security Operations (Master of IT Cybersecurity)  
**Target Infrastructure:** Pinnacle Manufacturing Corp (`pinnaclemfg.com`)

**Objective:** Reconstruct a web application defacement attack across all seven phases of the Lockheed Martin Cyber Kill Chain using SIEM telemetry.

---

## Scenario Brief
On the morning of Monday, 15 September 2024, staff arriving at work discovered the company's public website had been defaced. Leadership confirmed an intrusion and tasked the SOC team with running a full investigation. 

Logs were forwarded to Splunk under the index `pinnacle`. Telemetry sources include Apache web access logs (`access_combined`), HTTP streams (`stream:http`), Suricata IDS alerts (`suricata`), Windows Security event logs (`WinEventLog:Security`), Sysmon endpoint logs (`XmlWinEventLog:Microsoft-Windows-Sysmon/Operational`), and DNS traffic logs (`stream:dns`).

## Section 7 — Synthesis

### B1: Incident Summary Report

#### 1. Technical Executive Summary
On 15 September 2024, a sophisticated public website defacement attack was executed against Pinnacle Manufacturing Corp (`pinnaclemfg.com`). By correlating network IDS alerts, HTTP application streams, and Windows endpoint logs inside Splunk, the SOC team tracked an external adversary identifying themselves as the **"SH4D0W SYNDICATE"**. The threat actor moved through automated reconnaissance, exploited a critical web application flaw, established high-privilege persistent access on the local host, and implemented an active Cobalt Strike Command and Control (C2) beaconing channel.

#### 2. Kill Chain Phase Mapping & Analysis

* **Reconnaissance & Weaponization:** The attacker initiated automated perimeter scanning from the external source IP `198.51.100.42` using the **Nmap Scripting Engine**. They immediately transitioned to aggressive directory enumeration via **Gobuster 3.5** to uncover system entry points. Prior to the scanning phase, the adversary registered a look-alike staging domain (`cdn-pinnaclemfg.com`) mapped to their external malicious infrastructure (`192.0.2.150`). By analyzing system assets, the attacker identified that the target web server (`PINN-WEB01` / `10.0.10.50`) was running an outdated instance of **Joomla! 3.7.0**, weaponizing a known core SQL Injection exploit vector (**CVE-2017-8917**).
* **Delivery & Exploitation:** At `03:16:26 UTC`, an automated Python script (`python-requests/2.31.0`) successfully concluded a **178-attempt brute-force campaign** against the portal path `/administrator/index.php`, cracking the administrative credentials with the password **`Pinnacle2024!`**. Concurrently, the attacker leveraged the Joomla Core SQL Injection vulnerability to hijack operational session handlers.
* **Installation:** At `03:21:18 UTC`, the attacker manipulated the IIS Web Worker Process (`w3wp.exe`) to upload an arbitrary PHP script named **`media-uploader.php`** directly to the local directory `C:\inetpub\wwwroot\images\`. This web shell was immediately utilized to execute initial mapping commands (`whoami`, `ipconfig`, `systeminfo`). To cement their foothold, the attacker dropped a secondary malicious executable, **`svchost-update.exe`** (MD5: `7c9c6f6e561920680b9b2baefd756512`), into `C:\Windows\Temp\` via an interactive PowerShell session, elevating runtime execution privileges to **`NT AUTHORITY\SYSTEM`**.
* **Command & Control (C2):** Starting at `03:55:00 UTC`, the elevated binary initiated automated outbound TCP traffic over port `443` to the external IP `192.0.2.150`. Network intrusion logs caught this activity on a strict **300-second (5-minute)** recurrence interval, triggering Suricata signatures for an active **Cobalt Strike Beacon**.
* **Actions on Objectives:** For persistent local entry points independent of the web portal, the threat actor created a local backdoor account named **`svc_helpdesk`** and forcibly appended it to the high-privilege local **`Administrators`** group. Finally, the attacker modified internal Joomla templates, successfully injecting defacement text across the corporate landing views (`<h1>OWNED BY SH4D0W SYNDICATE</h1>`).

#### 3. Strategic Containment & Remediation Recommendations

1. **Host Isolation and C2 Network Disruption (Immediate):** Natively isolate `PINN-WEB01` from the internal domain environment to cut off active malware actions. Implement boundary firewall controls on the corporate gateway to drop all ingress/egress communication linked to the rogue IP `192.0.2.150` and sinkhole the typosquatted domain `cdn-pinnaclemfg.com`.
2. **Eradication of Local Backdoors & Persistence (Short-Term):** Terminate the malicious `svchost-update.exe` process and purge the backdoor web shell from the IIS web directory. Delete the unauthorized `svc_helpdesk` local user account. Enforce a global password reset for all enterprise administrative tiers, implementing robust multi-factor authentication (MFA).
3. **Application Vulnerability Patching & Re-imaging (Long-Term):** Re-image the web server operating system from a trusted golden image baseline to remove any hidden modifications. Prior to production re-deployment, upgrade the web infrastructure CMS from Joomla! 3.7.0 to the latest secure version, effectively closing the core SQL Injection (CVE-2017-8917) vulnerability vector.
